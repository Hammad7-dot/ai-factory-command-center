# AI Factory Command Center Implementation Plan

> Execute the approved design task by task, with independent workflow implementation and local integration review.

**Goal:** Deliver the integrated hackathon demonstration described in ../../design.md.

**Architecture:** Local Python modules separate synthetic data, trained models, evidence orchestration and Streamlit presentation. Artifacts stay on disk; human decisions use SQLite.

**Tech Stack:** Python, pandas, scikit-learn, PyTorch, Streamlit, MLflow, reportlab.

**Spec:** docs/design.md

## Global Constraints
- Synthetic sources are labelled throughout.
- No fabricated model metrics or LLM outputs.
- Human approval required before a final operational decision.
- Never upload pickle/model files; only local trained artifacts are deserialized.

## Tasks
- [x] Data and training: create factory/data.py, factory/models.py and train.py. Generate independent machine histories with delayed failure targets, dirty CSVs, joined production records, notes and independently seeded image splits. Fit train-only preprocessing. Compare logistic regression, Random Forest and ANN using validation F1; report held-out test metrics and CNN image metrics. Track runs and register selected model in MLflow.
- [x] Workflow: create factory/workflow.py and tests/test_workflow.py. Test retrieval abstention, simulation response to risk, structured four-agent evidence and supervisor audit validation. Implement source-grounded optional LLM explanations with honest offline fallback.
- [x] Application and reports: create app.py and factory/reporting.py. Integrate CSV, image, note and manual input, sensor explanations, Grad-CAM, scenario comparison, decisions and PDF download. Test Streamlit using AppTest and report text extraction/rendering.
- [x] Submission: write README.md, data documentation and presentation material. Run complete demo, verify saved metrics, model versions, PDF and dashboard, and package source and trained artifacts.
